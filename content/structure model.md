## Rule for adding future branches

Use this:

```text
A High Principia category should be broad enough to contain many future pages,
but specific enough that readers know what kind of knowledge lives there.
```

So:

```text
Good index-level branch:
├── Manaphysics

Too specific for index-level:
├── Mana Circles

Better:
Manaphysics
└── Mana Formation Theory
    └── Mana Circles
```

## Main home + cross-link rule

If a topic belongs to multiple places, choose one **main home** and cross-link from the others.

Example:

```text
Mana Thermodynamics
Main home:
Manaphysics → Mana Thermodynamics

Cross-links:
Thermodynamics → Related Fields
Physics → Manaphysics
Life Sciences → Mana Biology, if relevant
```

```text
Soul-Body Coupling
Main home:
Soul Biology or Biophysics

Cross-links:
Metaphysics → Soul Theory
Biology → Physiology
Physics → Biophysics
```

```text
Astrological Causality
Main home:
Astrology → Astral Causality

Cross-links:
Metaphysics → Causality
Cosmology → Cosmic Order
Anachysics → Causal Dynamics, if relevant
```

## Design principle

The index is **not the whole tree**.

It is the map of major territories. Each territory can unfold later without forcing you to redesign the whole structure. For now, keep High Principia stable and shallow; let the individual branch pages become detailed hubs.
